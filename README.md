# Medical AI Paper Reproduction

This repository contains my implementations and experiments based on research papers in medical artificial intelligence and deep learning.

The goal of this project is to better understand recent methods in medical image analysis by reproducing, evaluating, and extending ideas presented in academic literature. Each implementation focuses on understanding the methodology, rebuilding the experimental pipeline, and analyzing the strengths and limitations of the proposed approaches.

Topics explored in this repository include:

* Deep learning for medical image analysis
* Computer vision in healthcare
* MRI-based image classification
* Robust and trustworthy AI
* Adversarial machine learning
* Explainable AI for medical applications

For each reproduced work, I document:

* The original research problem and motivation
* The proposed methodology
* Implementation details
* Experimental setup
* Evaluation metrics
* Results and observations

The purpose of this repository is not only to reproduce existing methods, but also to develop a deeper understanding of how AI techniques can be applied reliably in real-world medical scenarios.
