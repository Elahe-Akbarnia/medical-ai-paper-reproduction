# Results

This directory stores experimental outputs generated after running the training and evaluation pipelines.

## Structure


### figures/

Contains visual outputs:

- Training curves
- Confusion matrices
- Confidence distribution plots
- Robustness comparison figures


### tables/

Contains numerical results:

- Classification reports
- Accuracy comparisons
- Precision, recall, and F1-score tables


### reports/

Contains experiment summaries:

- Baseline experiment reports
- Adversarial training reports
- Ablation study reports


## Note

This directory is currently empty because experiments require a GPU-enabled environment.
Results will be generated automatically after running the training and evaluation scripts.
